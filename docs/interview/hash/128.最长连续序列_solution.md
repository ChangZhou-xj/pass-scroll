# 最长连续序列 题解

## 题目描述

给定一个未排序的整数数组 nums，请找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

你可以假设每个数字最多只会被计算一次。

## 解题思路

### 方法一：Set + 优化遍历

为了在 `O(n)` 时间复杂度内解决问题，我们可以使用 `Set` 来快速查找数字是否存在，并避免重复计算。

具体步骤如下：
1. 将数组中的所有元素存入 `Set`，用于快速查找。
2. 遍历数组中的每一个数字，判断其是否是某个连续序列的起点（即 `num - 1` 不在 `Set` 中）。
3. 如果是起点，则使用 `while` 循环查找 `num + 1`、`num + 2`... 直到找不到为止，从而找到完整的连续序列。
4. 记录最长序列的长度，并最终返回。

## 代码实现

```javascript
var longestConsecutive = function (nums) {
  let numSet = new Set(nums);
  let max = 0;

  for (let num of numSet) {
    // 只有当 num 是序列的起点时才开始扩展
    if (!numSet.has(num - 1)) {
      let currentNum = num;
      let currentLength = 1;

      // 扩展序列
      while (numSet.has(currentNum + 1)) {
        currentNum++;
        currentLength++;
      }

      // 更新最大长度
      max = Math.max(max, currentLength);
    }
  }

  return max;
};
```

## 复杂度分析

### 时间复杂度
`O(n)`，其中 `n` 是数组的长度。每个数字最多只会被处理两次（一次遍历，一次扩展）。

### 空间复杂度
`O(n)`，用于存储 `Set` 中的所有元素。
