# 两数之和 题解

## 题目描述

给定一个整数数组 nums 和一个目标值 target，请你在该数组中找出和为目标值的两个整数。
你可以假设每组输入只会对应一个答案，且同样的元素不能重复使用。

## 解题思路

### 方法一：双循环
遍历数组中的每一对元素，检查它们的和是否等于目标值。这种方法的时间复杂度为 O(n^2)。

### 方法二：哈希表
使用哈希表存储已经遍历过的元素及其索引。对于每个元素 nums[i]，计算 complement = target - nums[i]，
然后检查哈希表中是否存在 complement。如果存在，则找到了解；如果不存在，将 nums[i]及其索引存入哈希表。
这种方法的时间复杂度为 O(n)。

```javascript
// 哈希表实现
var twoSum = function(nums, target) {
  let map = new Map();
  for (let i = 0; i < nums.length; i++) {
    let complement = target - nums[i];
    if (map.has(complement)) {
      return [map.get(complement), i];
    }
    map.set(nums[i], i);
  }
  return [];
};
```

## 复杂度分析

### 时间复杂度
- 双循环方法：O(n^2)，其中 n 是数组的长度。
- 哈希表方法：O(n)，其中 n 是数组的长度。

### 空间复杂度
- 双循环方法：O(1)，不需要额外空间。
- 哈希表方法：O(n)，需要存储最多 n 个元素的哈希表。
