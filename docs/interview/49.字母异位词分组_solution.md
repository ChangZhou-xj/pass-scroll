# 字母异位词分组 题解

## 题目描述

给定一个字符串数组 strs，请将所有 **字母异位词（Anagram）** 分组。换句话说，将所有包含相同字母但顺序不同的字符串归类在一起。

你可以假设每个字符串只包含小写字母。

## 解题思路

### 方法一：排序 + 哈希表

字母异位词是指一组字符串，它们的字符完全相同，只是顺序不同。因此，我们可以通过对字符串的字符进行排序，生成一个统一的键，从而将相同的字母异位词归类在一起。

具体步骤如下：
1. 创建一个 Map，键为排序后的字符串，值为对应的字母异位词分组列表。
2. 遍历字符串数组中的每一个字符串。
3. 对每个字符串进行排序，生成一个统一的键。
4. 如果该键已存在于 Map 中，则将当前字符串加入对应的分组；否则，创建一个新的分组。
5. 最后返回 Map 中所有值的数组形式。

## 代码实现

```javascript
var groupAnagrams = function(strs) {
  let map = new Map(); // 创建 Map 存储分组

  for (let s of strs) {
    // 将字符串拆分为字符数组 -> 排序 -> 拼接为新的字符串
    let key = s.split('').sort().join('');

    // 如果 key 存在，将当前字符串加入对应数组
    if (map.has(key)) {
      map.get(key).push(s);
    } else {
      // 如果 key 不存在，创建新的数组
      map.set(key, [s]);
    }
  }

  // 返回 Map 中所有值的数组形式
  return [...map.values()];
};
```

## 复杂度分析

### 时间复杂度
`O(n * k * log(k))`，其中 `n` 是字符串数组的长度，`k` 是字符串的最大长度。排序每个字符串需要 `O(k * log(k))`，而遍历整个数组需要 `O(n)`。

### 空间复杂度
`O(n * k)`，用于存储哈希表中的键值对。
