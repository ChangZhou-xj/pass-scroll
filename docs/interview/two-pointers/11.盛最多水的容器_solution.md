# 盛最多水的容器 题解

## 题目描述

给定一个长度为 n 的整数数组 height。有 n 条垂线，第 i 条线的两个端点是 (i, 0) 和 (i, height[i])。

找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

## 解题思路

### 方法：双指针
使用两个指针分别指向数组的两端，计算这两个指针所代表的两条垂线与 x 轴构成的容器的最大容量。然后移动高度较小的指针向中间靠拢，直到两个指针相遇。

这种方法的巧妙之处在于：
- 每次移动的是高度较小的指针，因为容器的容量取决于较短的那条垂线
- 通过逐步向中间靠拢的方式，我们可以在一次遍历中找到最大容量

### 时间复杂度：O(n)，其中 n 是数组的长度
### 空间复杂度：O(1)，只需要常数级别的额外空间

## 代码实现

```javascript
/**
 * 计算能够装下最多水的两个柱子的面积
 * @param {number[]} height - 一个数组代表每个柱子的高度
 * @return {number} - 返回最大面积
 */
var maxArea = function(height) {
  // 初始化左指针、右指针和最大面积
  let left = 0, right = height.length - 1, max = 0;
  
  // 当左指针小于右指针时，执行循环
  while (left < right) {
    // 计算当前两个指针所代表的两个柱子之间的面积
    let area = Math.min(height[left], height[right]) * (right - left);
    
    // 更新最大面积
    max = Math.max(max, area);
    
    // 移动高度较小的指针
    if (height[left] < height[right]) {
      left++;
    } else {
      right--;
    }
  }
  
  // 返回最大面积
  return max;
};
```

## 复杂度分析

### 时间复杂度
- O(n)，其中 n 是数组的长度。每个指针移动最多 n 次

### 空间复杂度
- O(1)，只需要常数级别的额外空间
