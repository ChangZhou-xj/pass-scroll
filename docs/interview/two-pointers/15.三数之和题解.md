# 三数之和

## 题目描述

给你一个整数数组 nums ，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k ，同时还满足 nums[i] + nums[j] + nums[k] == 0 。请你返回所有和为 0 且不重复的三元组。

注意：答案中不可以包含重复的三元组。

## 解题思路

本题采用排序加双指针法解决：

1. 首先对数组进行排序，这样可以方便地使用双指针法并进行去重处理
2. 遍历排序后的数组，以每个元素作为三元组的第一个数
3. 对于每个固定的第一个数，使用双指针法在剩余数组中寻找另外两个数
4. 使用左指针和右指针分别指向剩余数组的开始和结束位置
5. 计算三个数的和：
   - 如果和等于0，则找到一个有效三元组，同时移动两个指针
   - 如果和小于0，则左指针右移以增大和
   - 如果和大于0，则右指针左移以减小和
6. 在整个过程中进行去重处理，避免出现重复的三元组

去重处理包括两个方面：
1. 外层循环去重：如果当前元素与前一个元素相同，则跳过当前元素
2. 内层双指针去重：找到和为0的三元组后，跳过左右指针后续相同的元素

## 代码实现

```javascript
/**
 * @param {number[]} nums
 * @return {number[][]}
 */
var threeSum = function (nums) {
  let res = []
  const len = nums.length
  if (nums == null || len < 3) return res
  nums.sort((a, b) => a - b) // 排序
  for (let i = 0; i < len; i++) {
    if (nums[i] > 0) break // 如果当前数字大于0，则三数之和一定大于0，所以结束循环
    if (i > 0 && nums[i] == nums[i - 1]) continue // 去重
    let left = i + 1
    let right = len - 1
    while (left < right) {
      const sum = nums[i] + nums[left] + nums[right]
      if (sum == 0) {
        res.push([nums[i], nums[left], nums[right]])
        while (left < right && nums[left] == nums[left + 1]) left++ // 去重
        while (left < right && nums[right] == nums[right - 1]) right-- // 去重
        left++
        right--
      } else if (sum < 0) left++
      else if (sum > 0) right--
    }
  }
  return res
}
```

## 复杂度分析

- **时间复杂度**: O(n²)，其中 n 是数组的长度。排序的时间复杂度是 O(n log n)，外层循环遍历数组需要 O(n) 时间，内层双指针遍历需要 O(n) 时间，总体时间复杂度为 O(n²)。
- **空间复杂度**: O(1)，不考虑返回结果所需的空间，只使用了常数级别的额外空间来存储指针和临时变量。
