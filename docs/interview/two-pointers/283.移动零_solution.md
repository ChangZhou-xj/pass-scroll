# 移动零 题解

## 题目描述

给定一个数组 `nums`，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。
请注意，必须在不复制数组的情况下原地对数组进行操作。

## 解题思路

### 方法：双指针
我们可以使用双指针的方法来解决这个问题。具体步骤如下：

1. 初始化一个指针 `nonZeroIndex`，用于记录非零元素应该放置的位置。
2. 第一次遍历数组，将所有非零元素依次前移，并更新 `nonZeroIndex` 的位置。
3. 第二次遍历数组，从 `nonZeroIndex` 开始，将剩余位置补零。

这种方法可以保证非零元素的相对顺序不变，同时将所有零移动到数组末尾。时间复杂度为 O(n)，空间复杂度为 O(1)。

## 代码实现

```javascript
var moveZeroes = function(nums) {
  let nonZeroIndex = 0;

  // 将所有非零元素前移
  for (let i = 0; i < nums.length; i++) {
    if (nums[i] !== 0) {
      nums[nonZeroIndex++] = nums[i];
    }
  }

  // 将剩余位置补零
  for (let i = nonZeroIndex; i < nums.length; i++) {
    nums[i] = 0;
  }

  return nums;
};
```

## 复杂度分析

### 时间复杂度
- O(n)，其中 n 是数组的长度。我们进行了两次遍历，每次遍历的时间复杂度都是 O(n)。

### 空间复杂度
- O(1)，不需要额外空间，直接在原数组上进行操作。
