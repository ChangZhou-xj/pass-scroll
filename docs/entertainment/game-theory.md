# 博弈技巧

## 一、博弈基础理论

### 1. 基础猜拳机制与预判

+ **三种攻击相互克制**：普通攻击克制振刀架势，振刀架势能破解霸体蓄力攻击，霸体蓄力攻击又能压制普通攻击。博弈的核心是预判对手下一步动作，类似剪刀石头布的心理战。
+ **观察对手习惯**：通过多次对局积累经验，了解对手的出招节奏、闪避时机和蓄力习惯，从而针对性地调整策略。

### 2. 关键动作与时机

+ **闪避技巧**：闪避不仅是躲技能，更是取消自身攻击后摇、调整身位和观察对手的关键。要掌握好闪避的时机，避免按早或按晚导致破绽。
+ **振刀与反击**：振刀成功后是反击的黄金窗口，应立即接上控制技能或连招，如太刀的升龙浮空追击。
+ **蓄力攻击运用**：先手蓄力可以压制对手，迫使对方在振刀和对蓄之间做出选择。同时要注意蓄力的时间节点，避免被对手反制。

### 3. 距离与拉扯控制

+ **控距技巧**：通过上步、后撤和闪避控制与对手的距离，选择合适的进攻和防守时机。中远距离适合目押，近距离则需要快速反应。
+ **拉扯策略**：不要盲目进攻，学会通过拉扯骗对手先出招，再根据其动作进行反制。防守反击有时比主动进攻更有效。

### 4. 信息收集与决策

+ **观察对手行为**：注意对手使用的武器、技能、闪避次数和决策时间节点，判断其打法类型（如固定靶、移动靶等）。
+ **先验与后验博弈**：
    - **先验博弈**是根据经验和观察提前预判对手动作，主动出击。
    - **后验博弈**是在对手出刀后抓住时机反击，如抓白刀后摇、蓝顶白刀等。
+ **灵活切换策略**：根据对手的变化及时调整自己的博弈思路，避免被对手摸清套路。

### 5. 实战细节与技巧

+ **抓蓝霸体时机**：不要等蓝霸体完全消失再抓，应在蓝霸体即将结束时提前出刀，抓住对手的出刀前摇。
+ **受击与升龙**：被抓到僵直后，要观察对手的升龙动作再交受击，避免被假动作骗掉受击机会。
+ **多武器特点**：不同武器有不同的博弈侧重点，如太刀注重浮空压制，阔刀依赖霸体和蓄力爆发，需根据武器特性制定策略。

## 二、通用博弈原则

### 1. 先试后打，信息为王

+ 开局不要直接满蓄输出，先用假蓄力、走位试探，骗出对手的振刀、闪避或技能，再根据反馈决定下一步动作。
+ 每一次闪避、短蓄都是在"提问"，对手的反应就是"答案"，积累足够信息后再出手更稳。

### 2. 控制距离，避开劣势

+ 每种武器都有优势区间：长剑适合中远距离拉扯，太刀强在中近距爆发，阔刀擅长近身反打。避免在对手的优势距离硬拼，用走位和闪避把战斗拉回自己的舒适区。

### 3. 节奏多变，不贪连招

+ 长短蓄力交替、真假蓄力骗招，打乱对手预判。输出后立刻拉扯重置节奏，切忌站场贪刀被反打。

## 三、武器针对性技巧

### 1. 长剑

+ 主打中距离消耗，利用长蓄力逼迫对手交闪避，再衔接平 A 或短蓄追击。
+ 被近身时优先短闪 / 长闪拉开，避免在劣势距离硬拼。

### 2. 太刀

+ 快慢蓄交替骗振刀，对手空振后接真蓄力爆发。
+ 连招两段后穿插闪避重置节奏，灵活走位压制长剑、规避阔刀。

### 3. 阔刀

+ 以静制动，防守反击为主。等待对手先手露出破绽后，反手蓄力或振刀反打。
+ 切忌盲目追击灵活武器（如匕首、太刀）。

### 4. 匕首

+ 极致灵活拉扯，短蓄 + 轻击快速消耗，打一套就走，避免站场缠斗。
+ 利用高机动性贴脸，再通过闪避观察对手反应，决定下一步。

### 5. 远程武器（鸟铳、弓箭等）

+ 主要用于远程消耗和分割走位，压低对手血线后再切近战进场。
+ 避免无脑射击，精准命中即可，防止暴露位置或浪费机会。

## 四、蓄力博弈口诀

+ **能捏少闪**：宁可原地捏蓝也不乱闪，乱闪易被抓僵直吃连招；捏蓝可给对手压力、保障自身安全，还能抓对手出刀时机释放蓄力。
+ **能闪少振**：面对频繁出蓄力的对手，别频繁振刀，否则易陷入对方节奏、被骗振吃蓄力；优先用闪避躲蓄力，还可抓对手蓄力后摇或后续闪避打连招，仅遇蓄力怪时大胆振刀。
+ **先续先振**：己方先进蓄力、敌方后进时占优势，敌方大概率出蓄力，此时振刀成功率大幅提升。
+ **后续先闪**：己方后进蓄力处于劣势，出蓄力比对方慢、振刀易被抓后摇；可在敌方蓄力节点闪避，躲蓄力同时拿回先续优势。
+ **后续先出**：同为后进蓄力的应对方式，蓄到 1.0 直接出，防止对手近身抓取。
