# 自定义练习设置

进入训练营后按 F4（小配列键盘需 fn+4）打开设置，推荐使用自定义练习模式。

## 闪避训练

+ 太刀左蓄 1.0 用短闪躲避
+ 长棍右蓄 1.0 用双短闪躲后反抓
+ 双截棍左蓄用闪一振二或短接长反抓

## 目押练习

+ 长剑随机配不同蓄点，左蓄下蹲躲、右蓄长闪躲（需看到剑气再反应）
+ 斩马刀右蓄三段加纵击，短闪三次后蓄转振

## 碰瓷振训练

+ 选择双戟右蓄 2.0，与天海保持安全距离，待其蓄力打出后用蓄转振

## 连招验证

+ 连招练习模式下，天海能闪走的连招非真连（实战也可被闪），双压不适合此模式

## 瞄准练习

+ 拓展瞄准练习模式可练远程准度
+ 或关闭战斗模式将两个天海打到一起，练习冰女双冲和月下无限连

## 冷知识

+ 按 B 键可重置训练场（恢复天海位置、自身大招），连招失误后直接重开
