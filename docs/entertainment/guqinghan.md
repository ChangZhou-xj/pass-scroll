# 顾清寒进阶练习

> 来源：@好运大王

## 升龙开大一套秒

+ 长剑（链剑）
+ 太刀（横刀）
+ 双刀双戟
+ 双截棍

摁 w 的时机：在升龙的时候人物重合前摁 w，重合时开大的时候就要及时松开 w（点大招的时候如不松开会导致敌方落地）

小跳 f 的时机：需要在大招结束的一瞬间，切记先小跳再 f 一定不要卡预输入

## F技能

+ 对方普攻，可以跳A；对方蓄力，可以抓僵直打连招；
+ 顾清寒破冰，飞刀拳刃可以无脑跳A，其他武器有被蓝顶的风险

## 奥义

1. 小跳急停
2. 蓄力急停
3. 啪地板性能不好，需要搭配 长棍、链剑
