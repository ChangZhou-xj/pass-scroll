# 基础身法

**短闪 —— 基础身法短闪操作、特性及实战应用技巧。**

+ **操作核心要点**：短闪操作方式为点按方向键加 shift，拥有无敌帧长、后摇长的特性，多用于规避对手进攻手段。
+ **操作避坑指南**：短闪过程中预输入捏蓝等动作会打断后半段无敌帧，易吃伤害或被抓；需松开所有按键等无敌帧跑完再衔接操作；连续点按闪避、磁轴键盘短键程会导致小丑翻滚，后者可回调设置解决。
+ **武器适配差异**：双刃、长兵器的短闪速度比其他武器更快；飞刀短闪后有低头动作，侧短闪时最明显，可规避长兵器和单刃的左键抓闪。
+ **实战规避策略**：半贴蓄状态下后短闪可闪干净太刀百裂斩；面对蓄力距离远的武器，需卡蓄点精准短闪；链剑双戟这类蓄力持续久的攻击，推荐用侧闪出攻击范围。
+ **组合闪启动技巧**：短闪是双短闪短接长、R 闪等组合闪的常见启动闪；未等无敌帧跑完就输入下一个闪，会导致组合闪变成翻滚。

## 修刀闪

修刀闪即 R 闪，操作流程为短闪过程中输入修刀键打断闪避，再用长闪或短闪打断修刀；需保证修刀与第二个闪衔接快速，过早用修刀打断短闪会提前结束无敌帧，可能被对手抓取。

+ **技能优劣特性**：优势是可快速拉开远距离，误导对手误判自身闪避后摇，使其错误出刀露出破绽；缺陷是使用需消耗至少两格精力，现版本多数玩家选择振刀沉默天赋，滥用修刀闪易导致精力不足。
+ **防抓反抓场景**：玩家抓刀或嫖刀失误时，若对手跟闪欲抓短闪，可使用修刀闪拉开身位防抓，或用 R 长闪快速进蓝完成反抓；被对手持续跳 A 打僵局时也适用该操作。
+ **控距脱战场景**：玩家陷入劣势博弈时，比如打出对手双节棍横拦、常规处理胜率低的情况，可使用修刀闪拉开距离规避本轮博弈，实现快速脱战。
