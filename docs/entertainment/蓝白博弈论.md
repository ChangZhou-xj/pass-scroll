# 蓝白博弈论：先蓄、同蓄、后蓄的完整博弈框架

> 本文由三份学习总结（原文见文末）糅合而成，以三种蓄位为主线，统一术语与蓄点定义。

## 〇、前置框架：分层、蓄点、蓄位

### 博弈分层

| 层级 | 蓄力区间 | 内容 | 地位 |
| --- | --- | --- | --- |
| 蓝白博弈 | 0 – 0.9s | 白刀（平A）与蓝霸体的相互克制 | 底层基础，优先练习 |
| 强博弈 | 1.0 – 2.0s | 满蓄、绕背闪、振刀的克制循环 | 进阶，建立在蓝白能力之上 |

基础克制关系：**蓝吃白，白抓闪，蓝顶反嫖刀**——蓝（蓄力霸体）吃白（平A），白刀抓闪避后摇，蓝顶反制嫖刀。

### 蓄点坐标系

蓄点数字统一理解为**蓄力秒数**（1.0s = 满蓄蓝霸体释放点）：

- **0.3s = 蓄闪预判点**：对手常在此蓄闪拉开，使用频率低，属基础预判型博弈点
- **0.7s = 蓝白主博弈点**：嫖刀、抓闪、蓝顶全部围绕此点展开，黄金节点
- **1.0s = 满蓄蓝霸体释放**；1.2 / 1.5 / 2.0s 属强博弈蓄点

### 三种蓄位

同一时刻双方蓄力进度的位置关系，决定你能做什么：

- **先蓄**：你比对方早捏蓝（压迫位）——你到 0.7 时对方才约 0.3
- **同蓄**：双方同时起蓄（最常见）——蓄点始终同步
- **后蓄**：对方先捏，你慢进蓝（被动位）——对方到 0.7 时你才约 0.1–0.4

**贯穿三蓄位的总规则：嫖刀永远卡「对方」的 0.7 蓄点；对方未到 0.7 时出刀 = 垃圾刀（无效刀）。** 三种蓄位的全部差异，本质上都是这一条规则的推论。

---

## 一、先蓄：压迫位，禁嫖

**位置关系**：你先到 0.7 时，对方才 0.3 左右——他还没到他的决策点。

### 0.3 节点：不要嫖刀

对方大概率在 0.3 蓄闪拉开，你此时嫖 = 白给，还会被对方蓝顶。最优解是继续捏到 0.7，预判他蓄闪、准备抓闪；或稳捏 1.0 逼他振/闪。**先蓄的优势是压迫，不是急着嫖刀。**

### 0.7 节点：二选一

1. **进攻**：0.7 松蓄出白刀，抓他蓄闪的后摇（预判闪）
2. **保守**：继续捏，等他动作——他敢出刀你直接蓝顶（容错最高）

### 为什么先蓄禁嫖（机制解释）

先蓄时你到 0.7、对方才 0.3，对方未到自己的 0.7 蓄点，你的刀卡不到他的决策点，属于**垃圾刀**。所以「先蓄禁嫖」不是口诀玄学，而是「卡对方 0.7」总规则的直接推论——嫖刀只适合同蓄、后蓄。

### 先蓄时的防守

- 对方对你嫖刀：可**蓝顶**（最稳，全蓄位通用），也可用**闪A抓A闪**（先蓄场景允许，但必须提前预输入，看到再反应会砍在对方长闪进蓝上）
- 抢到先蓄后**不要乱跟闪**：要么蓄力压闪，要么预判闪A抓A闪

---

## 二、同蓄：黄金位，0.7 嫖刀

**位置关系**：双方蓄点同步，对方到 0.7 时你也正好 0.7——唯一能用自己的 0.7 卡到对方 0.7 的蓄位。

### 0.3 节点：观察对手习惯

- 对手爱 0.3 闪 → 你提前预闪、压他后闪，出白刀抓闪
- 对手喜欢硬捏 → 继续捏到 0.7

### 0.7 节点（黄金最优节点）：卡 0.7 嫖一刀

**对局中使用率最高的最优动作。** 同蓄 0.7 嫖刀风险最低、对手反应时间最短：嫖中拿僵直，嫖空有后续预输入兜底，不容易被蓝顶反打。

嫖完之后的后续有两条线，对应防对手的不同反制：

1. **嫖完立刻预输入闪避**（防对手蓝顶反打）
2. **嫖完原地捏蓝接 2A，不要闪**（防对手闪A抓A闪——用蓝霸体顶掉他抓进来的那一刀）

两条线并不矛盾，选哪条是下一层的读习惯，无脑套用单一路线会被针对性反制。

### 同蓄时的防守

- 对方卡 0.7 嫖你：**优先蓝顶**（原地捏蓝顶掉他的平A，最稳）
- 也可用**闪A抓A闪**进攻型反制（同蓄场景允许，同样必须提前预输入）
- 闪A抓A闪分两种：闪A抓A**长闪**（立马出刀）、闪A抓A**短闪**（捏蓝刀）

## 三、后蓄：被动位，蓝顶拦顶

**位置关系**：对方到 0.7 时你才 0.1–0.4，蓄力全面落后。核心思路：**慢进蓝拦顶**。

### 0.3 节点：不要乱动

不要主动出白刀，容易被他抓。

### 0.7 节点：等他出刀，蓝顶砍断

等他在 0.7 出嫖刀/出蓄力，你后蓄的蓝霸体直接**蓝顶**砍断他的攻击。**后蓄的价值就是蓝顶反制对方嫖刀。**

- **后蓄不要抓闪**：蓄力落后意味着你的闪和刀都慢半拍，后蓄抓闪基本都会空
- **后蓄禁止闪A抓A闪**：此场景对方出刀直接蓝顶即可
- 例外：对方 0.7、你仅 0.1 时，你出刀也能卡到对方的 0.7 蓄点（后蓄可嫖的理论依据），但被动位求稳仍以蓝顶为主

### 后蓄的延伸用法

对手一直猛蓄猛出不放 → 后蓄等 1.0，准备**振刀**（进入强博弈层手段）。

## 四、三蓄位速查表

| 蓄位 | 0.3 节点 | 0.7 节点 | 禁止事项 | 核心思路 |
| --- | --- | --- | --- | --- |
| 先蓄 | 不嫖，捏到 0.7 | ①预判蓄闪→松蓄白刀抓闪后摇；②继续捏，他敢出刀就蓝顶 | **禁嫖**（垃圾刀） | 压迫 |
| 同蓄 | 观察习惯：爱 0.3 闪→预闪抓闪；硬捏→捏到 0.7 | **卡 0.7 嫖一刀 + 预输入后续**（黄金最优解） | 嫖完别无脑单一后续 | 0.7 嫖刀 |
| 后蓄 | 不乱动、不出白刀 | 等他出嫖刀/出蓄力→蓝顶砍断 | **禁抓闪、禁闪A抓A闪** | 慢进蓝拦顶 |

一句话口诀：

> **先蓄不嫖，捏 0.7 抓闪；同蓄 0.7 嫖 + 预闪；后蓄不抓闪，等他出刀蓝顶。**

## 五、强博弈层：蓄力克制闭环

蓝白层打穿之后进入 1.0–2.0s 的强博弈层，克制关系同样成环：

```text
1.0蓄力 ──被克──▶ 蓄闪（远距离S闪 / 近距离绕背闪）
蓄闪   ──被克──▶ 0.3秒闪A（蓄到0.3秒长闪出刀，斩断对手S长闪）
0.3闪A ──被克──▶ 1.0蓄力
        （三环闭环，互相克制）
```

更高层的延伸链：

- 1.0 蓄力 → 被**绕背闪**克
- 绕背闪 → 被 **1.2 蓄力**克（等对手闪完再放蓄力）
- 1.2 蓄力 → 被**绕背闪振刀**克（预判对手蓄力压闪时直接振刀）
- 绕背闪振 → 被 **1.5 / 2.0 蓄力**克（等对手闪振结束再放蓄力，或预判抓振刀后摇）

蓝对蓝的释放时机：卡在对手蓄力 0.5–0.6 秒后动作，对手会下意识放 1.0 蓄力，你**慢放 1.2 蓄力**即可规避蓝顶；实战多为 1.1/1.2 蓄力，给反应留空间。注意 1.2 在链中既是「克制绕背闪」的手段又「被绕背闪振」克——强博弈层没有绝对安全的蓄点。

## 六、常见误区自查

1. **以为嫖刀卡的是自己的 0.7**——卡的是对方的 0.7，先蓄时自己到 0.7 出刀正是新手最常见的垃圾刀
2. **把 0.3 当成进攻节点**——0.3 是蓄闪预判点（先闪压后闪 / 0.3 秒长闪斩断 S 长闪），不是嫖刀点
3. **嫖完只会一种后续**——预输入闪避与捏 2A 蓝顶是两条防不同反制的线，要读习惯切换
4. **后蓄也想闪A抓A闪**——慢半拍必空，直接蓝顶
5. **看到再反应**——所有蓄点操作都是提前性质的预判，闪A抓A闪不预输入会砍在对方长闪进蓝上
6. **忽略适用前提**——高延迟优先保守蓝顶、少嫖刀；0.3/0.7 秒数基于太刀、长剑类单段蓄力，匕首、双戟节奏要提前
7. **混淆两个「嫖刀」**——蓝白层嫖刀 = 松蓄出白刀；强博弈层「卡 0.5–0.6s 慢放 1.2」是蓝对蓝释放时机，同名不同物

## 七、反制链速查与练习顺序

| 对手的行为 | 你的最优解 |
| --- | --- |
| 0.7 嫖你白刀 | 蓝顶（最稳） |
| 习惯 0.3 蓄闪跑路 | 0.3 提前闪，抓他闪后摇 |
| 一直猛蓄猛出不放 | 后蓄等 1.0，准备振刀 |
| 你嫖刀被蓝顶反吃 | 自检：你在先蓄状态嫖了，先蓄禁嫖 |

练习顺序：先练**同蓄 0.7 嫖 + 预闪** → 再练**后蓄蓝顶** → 最后练**先蓄抓蓄闪**。

底线：蓝白博弈永远是读习惯。公式是基准，打两把记住对方是爱 0.3 闪还是硬捏，再切换策略。

## 附：三份原始总结

蓝白博弈核心节点最优解（蓄点：0.3 / 0.7，底层框架：先蓄｜同蓄｜后蓄）

蓝白：双方对捏蓄力，0.3=早蓄点（蓄闪节点），0.7=核心嫖刀/抓闪节点，1.0=完整蓝霸体释放；蓝（蓄力霸体）吃白（平A），白抓闪避后摇，蓝顶反嫖刀

**一、三种蓄位的最优选择（直接背公式）**

✅ 情况1：你【先蓄】（你比对方更早捏蓝）

- 0.3节点：不要嫖刀！对方大概率0.3蓄闪拉开；你嫖=白给，会被对方蓝顶。👉最优：捏到0.7，预判他蓄闪，准备抓闪；或者稳捏1.0逼他振/闪。先蓄优势是压迫，不是急着嫖刀

- ❌先蓄千万别主动嫖，嫖刀只适合同蓄、后蓄

✅ 情况2：双方【同蓄】（同时起蓄，最常见）

- 0.3节点：观察，看对手习惯。对手爱0.3闪 → 你提前预闪压他后闪出白刀抓闪；对手喜欢硬捏 → 继续捏到0.7

- 0.3：不要乱动，不要主动出白刀，容易被他抓
- 0.7最优：等他在0.7出嫖刀/出蓄力，你后蓄的蓝霸体直接蓝顶砍断他的攻击
- 👉后蓄不要抓闪，后蓄抓闪基本都会空；后蓄的价值就是蓝顶反制对方嫖刀

**二、一句话极简口诀（实战脑子里直接用）**

先蓄不嫖，捏0.7抓闪；同蓄0.7嫖+预闪；后蓄不抓闪，等他出刀蓝顶。0.3是蓄闪预判点，0.7是蓝白主博弈点

2. 对手习惯0.3蓄闪跑路 → 你：0.3提前闪，抓他闪后摇

### 总结 2

这个视频是永劫无间的蓄力博弈与蓝白刀克制关系教学，核心内容如下：

**一、蓄力博弈克制关系**

1. 1.0蓄力：被绕背闪、远距离S闪克制
2. 绕背闪：被1.2蓄力克制（等对手闪完再放蓄力）
3. 1.2蓄力：被绕背闪震刀克制（预判对手蓄力压闪时直接震刀）
4. 绕背闪震：被1.5/2.0蓄力克制（等对手闪震结束再放蓄力，或预判抓震刀后摇）

**二、蓝白刀博弈与实战技巧**

1. 蓝顶机制：
   - 新手蓄力博弈阶段禁止乱嫖刀，否则会被蓝顶
   - 正确嫖刀时机：卡在对手蓄力0.5-0.6秒后再出刀，此时对手会下意识放1.0蓄力，你慢放1.2蓄力即可规避蓝顶
   - 实战中多为1.1/1.2蓄力，给反应留空间
2. 闪A与跟闪误区：
   - 抢到先蓄后不要乱跟闪，要么蓄力压闪，要么预判闪A抓A闪
   - 闪A抓A闪分两种：闪A抓A长闪（立马出刀）、闪A抓A短闪（捏蓝刀）
   - 反制对手闪A抓A闪：A完后捏蓝2A不要闪
3. 蓄闪克制闭环：
   - 1.0蓄力被蓄闪（远距离S闪、近距离绕背闪）克制
   - 蓄闪被0.3秒闪A克制（蓄力到0.3秒时长闪出刀，斩断对手S长闪）
   - 0.3秒闪A被1.0蓄力克制，形成完整博弈闭环

视频通过实战演示讲解了每一种克制关系的操作方法，适合新手学习蓄力博弈基础逻辑。

### 总结 3

按照博弈框架，结合视频内容整理重点：

**一、整体博弈分层**

1. 蓝白博弈（0-0.9蓄力）：博弈底层基础，需优先练习
2. 强博弈（1.0-2.0蓄力）：进阶对抗阶段，建立在蓝白博弈能力之上

**二、蓝白博弈核心蓄点**

蓝白博弈的核心是围绕两个固定蓄点展开，通过提前抢蓄点去除多余操作：

1. 0.3蓄点
   - 基础思路：0.3中闪抓蓄闪，原理是预判对方在0.3蓄点会选择蓄闪拉开，通过先闪压后闪完成克制
   - 特点：使用频率较低，属于基础预判型博弈点
2. 0.7蓄点（蓝白博弈核心）
   - 本质逻辑：蓝白博弈是"矛（进攻）"与"盾（防守）"的对抗，所有操作围绕0.7蓄点展开
   - 进攻操作：在0.7蓄点卡蓄点嫖刀，灌输固定博弈节奏
   - 防守操作：在0.7蓄点反制卡蓄点嫖刀，用闪A抓A闪完成克制
   - 操作关键：闪A抓A闪需提前预判（而非看到后再反应），否则会砍在对方长闪进蓝上

**三、蓝白博弈框架（三种对蓄情况）**

1. 卡蓄点嫖刀规则
   - 核心原则：永远卡对方的0.7蓄点出刀，未到对方0.7蓄点时出刀属于垃圾刀
   - 禁止出刀场景：先蓄情况（己方0.7，对方0.3），对方未到0.7蓄点，出刀无效
   - 可出刀场景：同蓄（双方蓄点一致）、后蓄（对方0.7，己方0.1），此时出刀能卡到对方0.7蓄点
2. 反制卡蓄点嫖刀规则
   - 核心原则：优先蓝顶，再考虑闪A抓A闪
   - 禁止闪A抓A闪场景：后蓄情况（对方0.7，己方0.4），对方出刀属于垃圾刀，直接蓝顶即可
   - 可闪A抓A闪场景：先蓄、同蓄情况，可提前抢先闪完成克制
3. 反制闪A抓A闪操作
   - 操作方法：嫖刀后原地捏2A，通过蓝顶直接克制对方的闪A抓A闪

**四、蓝白博弈核心逻辑**

所有蓝白操作的本质是预判，蓄点操作均为提前性质，通过固定0.3、0.7蓄点的操作公式，去除多余的垃圾刀、垃圾闪，形成稳定的蓝白博弈节奏。
