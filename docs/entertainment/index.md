## 第一阶段：基础准备

身体状态与练习环境是一切技巧的底座。

### [提高FPS](fps)

- **内容**：反应速度的综合系统（视觉捕捉、大脑处理、肌肉记忆、预判），涵盖饮食、运动、拉伸与训练日程。
- **要点**：低 GI 饮食避免"糖分崩溃"、规律补水、咖啡因甜点区、有氧运动提升神经传导、手腕颈部拉伸防神经压迫。
- **何时读**：训练初期建立习惯；长期训练后枪法变形、反应下滑时回顾。

### [自定义练习设置](practice-settings)

- **内容**：训练营 F4 自定义练习模式配置，含六类练习方法与冷知识。
- **要点**：闪避训练（太刀/长棍/双截棍）、目押练习（长剑/斩马刀）、碰瓷振训练（双戟）、连招验证、瞄准练习、B 键重置训练场。
- **提示**：后续所有阶段的连招与博弈都应在训练营反复验证，连招失误直接 B 重开。

## 第二阶段：武器体系

先掌握具体武器的连招与应对，建立实战工具箱——"每种武器怎么打"。

### [武器基础实用连招应对策略总结](weapon-combos)

- **内容**：15 种武器（长剑、链剑、太刀、横刀、阔刀、斩马刀、长枪、长棍、双刀、双戟、匕首、扇子、双截棍、拳刃、飞刀）的基础连招、处决连招、蓄力应对策略与高级技巧。
- **核心机制**：蓄点阶段（先入 1.0 占优）、控距目押、蓄转振。
- **用法**：作为查阅手册。按主玩武器精读，其余武器了解特性以便应对。配合[自定义练习设置](practice-settings)在训练营逐项验证。

## 第三阶段：核心博弈理论

在掌握各武器后，提炼跨武器的博弈原则——从背连招升级为读对手，理解"为什么这么打"。

### [博弈技巧](game-theory)

- **内容**：博弈基础理论 + 通用原则 + 武器针对性技巧 + 蓄力博弈口诀。
- **核心概念**：
    - **猜拳机制**：普攻 → 振刀 → 蓄力 → 普攻（循环克制）
    - **先验 / 后验博弈**：预判主动出击 vs 抓后摇反击
    - **蓄力口诀**：能捏少闪、能闪少振、先续先振、后续先闪、后续先出
- **内容关联**："武器针对性技巧"是对[武器基础](weapon-combos)各武器应对的宏观提炼；"蓄力口诀"中的"先续先振"对应[斩马刀](zhanmadao)的"先蓄先振（优势博弈论）"。

### [基础身法](movement)

- **内容**：短闪操作、特性及实战应用；修刀闪（R 闪）的原理、优劣与防抓/脱战场景。
- **要点**：短闪无敌帧长但怕预输入打断；修刀闪消耗两格精力，滥用易陷入精力危机。

## 第四阶段：专项深入

在武器与理论之上，针对单武器、远程、单角色进行深度拓展。

### [斩马刀学习分享](zhanmadao)

- **内容**：斩马刀完整体系 —— 磐石架势（普通磐 / 无敌磐 / 活磐 / 死磐）、先手与后手博弈、身法跑图、英雄对位、每日自省口诀与微操补遗。
- **亮点**："先蓄先振"优势博弈论、"战前五问"心态检查表、不可磐石招式清单。
- **关联**：文末强调"远程武器的熟练度至关重要"，配合[远程博弈](ranged-combat)阅读。

### [远程博弈](ranged-combat)

- **内容**：远程武器体系 —— 蓄力 C 切 / 跳切 / 闪切、钩锁狙（跳钩 / 原地 / 反钩）、射击机制与实战应用（抓捏蓝、钩锁抓闪、对射身法、预瞄、枪斗术）。
- **提示**：远程切回近战必须用闪切，时刻保留一格精力防被近身。

### [顾清寒进阶练习](guqinghan)

- **内容**：顾清寒角色进阶 —— 升龙开大一套秒（长剑 / 太刀 / 双刀双戟 / 双截棍）、F 技能、奥义、冰女极意。
- **先修**：[武器基础](weapon-combos)中相关武器的升龙连招（摁 w 与小跳 f 的时机是关键）。

## 术语与连招标记法

- **键位**：`a`/`A` = 左键（平击），`b`/`B` = 右键（纵击）；`asa`、`bsb` 为攻击序列；`ca` 为蓄力接平 A。
- **连招书写**：行内代码 + `→`，如 `a → 升龙 → 钩锁 → 右蓄 1.0`。
- **蓄力**：`1.0`/`1.5`/`2.0`；"捏蓝" = 按住蓄力进入蓝色霸体。
- **闪避**：短闪 / 长闪 / 中闪；"干净闪" = 无多余输入的纯闪避。
- **振刀**：统一用"振刀"（不写"震刀"）。派生：碰瓷振、闪一振二、控距目押、蓄转振、蓝顶白刀。
- **磐石**：斩马刀专属架势，分普通磐 / 无敌磐 / 活磐 / 死磐。
- **天海**：训练营假人英雄。
