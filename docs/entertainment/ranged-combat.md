# 远程博弈

> 来源：@火刃

远程武器是《永劫无间》中建立博弈优势的关键。它能在对手近身之前造成伤害，无论是追击还是逃跑都极具价值。本指南将系统讲解远程的核心操作、钩锁配合及实战策略。

## 一、远程基础切换技巧

1. **蓄力C切**：在近战状态下进行左键蓄力攻击时，不松开按键直接按C键蹲下，然后切换到远程武器并松开射击。这种方法适用于需要稳定射击的情况。
2. **蓄力跳切**：同样是在近战状态下的左键蓄力攻击过程中，轻按空格键做一个小跳跃动作之后立即切换至远程武器并完成射击。这种方式适合于调整角色高度或位置以获得更好的射击角度。
3. **蓄力闪切**：在执行近战蓄力攻击的同时使用闪避技能（无论是长闪还是短闪），紧接着切换成远程模式并释放射击。此方法能够根据具体情况灵活改变与敌人之间的距离。

⚠️ 重要提示：近战切远程可用C切或跳切，但远程切回近战必须用闪切。因此，时刻要保留一格精力用于紧急切换回近战，防止被近身。

## 二、钩锁狙

钩锁与远程是一个核心体系，以下是几种常见的钩锁射击连招。

### 跳钩狙

操作：近战蓄力 → 跳起来 → 出钩锁 → 钩中瞬间小跳取消后摇 → 切远程射击。要点：练习定位能力，确保钩中后能准确射击。

### 原地钩锁狙

操作：近战蓄力 → 直接出钩锁 → 在人物转头瞬间 → 小跳 + 切远程射击。要点：时机要求高，小跳早了会失误，需多练习找感觉。

### 反钩 (Counter Hook)

原理：当你直接出钩时，会玩的对手会利用无敌帧（如蓄力，打药）进行反钩，抓你的僵直。

应对方法：

1. 先钩先射：出钩后若感觉不对，立即切远程瞄准，准备射击反钩的对手。
2. 双钩打断：预判对手反钩，立即连出第二根钩锁，打断其反钩动作。

## 三、远程射击机制与实战策略

提高游戏命中率需掌握以下机制及策略：

1. 弹道偏移时，瞄准对方中右部；
2. 利用对手攻击后硬直期射击以应对攻击挡子弹；
3. 对非蓝霸体状态敌人优先射击或近战破除霸体状态。

## 四、实战应用场景

掌握何时何地使用远程武器至关重要。

#### 抓"捏蓝"时机

当对手捏蓝霸体且对你没有直接威胁时，他就像一个固定靶，是绝佳的射击机会。

#### 钩锁抓闪

原理：钩锁不仅是位移，也可以抓取对手的闪避动作。时机：1. 对手无意义乱跳时；2. 预判到对手会闪避时；3. 进行反钩操作时。风险：如果钩空，自己会陷入僵直，被对手反制。

#### 对射时机 (抓Timing)

原理：当对手射击或蓄力时，会有一个短暂的停顿（急停）。操作：自己先不规则移动，当对手开枪瞬间，你立即急停并瞄准他，利用他的停顿进行射击。

#### 对射身法

为避免因频繁闪切而耗尽精力，可采用非闪避的身法。例如，在远程蓄力时，进行不规则的左右横跳，让对手难以瞄准，然后比拼谁急停定位更准。

#### 预瞄 (Aim Prediction)

不要用准心追着移动的对手跑，这很难跟上。而是要预判对手的走位，将准心提前放在他未来可能出现的位置（如落点、侧移路径），等他走进你的准心再射击。如果预判错误，再进行快速甩狙调整。

#### 枪斗术

`蓄力 → C切远程 → 松开射击 → 闪切近战`
