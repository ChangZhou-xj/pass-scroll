# 永劫无间：斩马刀进阶体系化教学

> 致谢：搞笑的涛弟、小猫小狗诗社、克烈、修柔（永劫无间）、永劫无间公众号等

## 一、基础机制与连招逻辑

### 1. 普攻与连招特性

#### 核心连招公式

`左键(A) → 右键(B)`

+ **左键（A）起手优势：** 左键攻击后摇短，能更快衔接第二段攻击
+ **右键（B）强力二段：** 第二段右键前摇短，爆发快且不易被振刀
+ **战术价值：** 这是最稳健的平A连招，兼顾速度与伤害

#### 特殊连招技巧

+ **B2抓短闪：** `A1 + B2` 走一步可抓短闪
+ **连招：** 技能或长剑/棍子升龙，最高点后长闪 + `A1 + A2`（A2第一段可钩锁打断 + B）

#### 追击与壁击

+ 右键B攻击距离远，右键蓄力自带一段位移追击
+ 壁击后可稳定接右键B或转振刀

#### 蓄力特性

+ 蓄力攻击是三段，不同于其他武器

---

### 2. 核心机制：磐石

斩马刀的灵魂在于"**磐石**"架势，根据状态分为以下几种：

#### 磐石类型

+ **普通磐：** 出招瞬间产生拼刀，或捏蓝时被平A触发
+ **无敌磐：** 白刀 + 鼠标任意键二段攻击（不可移动）
+ **活磐（可控磐）：** 与对方拼刀后，松开攻击键，在人物完全恢复站立姿态前可触发反击
    - _原理：_ 利用"控磐"技巧，实现慢放招式

#### 取消死磐技巧

+ 下蹲
+ 跳跃
+ 短闪/战步
+ 钩锁

---

## 二、核心博弈体系

### 1. 先手博弈：右键蓄力的压制力

**起手思路：** 捏住右键蓄力，利用霸体和位移优势进行"猜拳"

#### 对手应对与我方对策

**情况A - 对手平A/振刀**

+ 直接释放右键蓄力攻击

**情况B - 对手捏蓄力**

+ 转振刀（高风险高回报）
+ 拼刀（进磐石）
+ 闪避蓄力（拉开距离重新博弈）

**情况C - 对手闪避**

+ 前闪平A抓落地
+ 使用 `左A → 右B` 无敌磐

---

### 2. 后手博弈：磐石后的选择

当触发磐石后，根据是否受到后续攻击决定对策：

#### 有受击

+ 直接释放磐石反击（通常为柄击或多段磐石直接释放）
+ **注意：** 慢放可降低风险

#### 无受击（对方停手）

**慢战步拉开：**

+ 重新捏住右键蓄力
+ 将后手转为先手

**柄击（慎用）：**

+ 高手能目押柄击进行振刀
+ 建议绕背释放或慢放

**慢放优势：**

+ 用于抓对方的振刀后摇或压闪避

---

### 3. 先蓄先振（优势博弈论）

**基本逻辑：** 我方先蓄力，处于优势地位

#### 对手对策与我方解法

> **注意：** 理论概率统计显示25%博弈失败，但实际场景多变
>

+ **对手长闪绕背（最优解）：** 抓我方振刀后摇 → ❌ 劣势
+ **对手短闪/振刀：** → ⚖️ 平局
+ **对手蓄力拼刀：** 直接释放或转磐石 → ✅ 优势

---

## 三、身法与跑图技巧

### 1. 通用身法

+ **跑路/追击：** 左键蓄力滑步（位移长）
+ **无精力时：** 滑铲 + 跳A
+ **闪避细节：**
    - 控制精力最好保留一半精力格
    - 短闪：练习干净闪，无敌帧长
    - 长闪：后摇短，无敌帧短
    - 中闪：无敌帧较长，后摇较短

---

### 2. 地形身法

#### 上树（飞袭）

+ **基础：** 最高点一直按左键
+ **进阶：** 最高点 `左键 + Shift + 左键 + Shift`（更利于观察，但也易被钩锁僵直）

#### 城区/房檐

+ 利用墙壁壁击翻越房檐（视角朝上）
+ 房檐蹲姿利用视野盲区

#### 空蓄（壁击空蓄）

+ 飞袭高点左键 → 侧长闪 → 右键蓄力

---

## 四、实战心态与"错题本"总结

### 1. 战斗意识

#### 拒绝预输入

+ **核心原则：活磐石** 不要预输入指令！
+ 看到人先观察英雄和武器，再决定怎么打

#### 博弈细节

+ 先蓄力不要着急闪，观察对手动作
+ **对手喜欢振刀？** 变招骗振，预判闪A，此时绝对不放AB连招
+ **对手很呆？** 多用近战、慢战步、慢磐石压制
+ **血量优势？** 多骗振，慢放柄击，稳扎稳打
+ **K头原则：** 如果不是最后一下必杀，尽量不要乱出刀干扰队友

---

### 2. 防御与拉扯

#### 拉扯处理

+ 被打一套后，先拉扯，不要急着反打
+ **起身：** 先按方向键位移，再考虑进磐石

#### 面对钩锁

+ **被钩锁飞袭时：** 不要拼刀，不要捏蓝，直接闪避（要学反勾）
+ **敌人钩锁起飞后：** 不要贪远程，先拉开距离

#### 打药博弈

+ 被刘炼（及类似控制）抓到，直接F+5快速打药，别想着蓄力反打
+ 打药时要先取消打药动作才能升龙或闪避

---

### 3. 英雄对位指南

+ **宁红夜：** 控距防F，躲F后往地形复杂处跑
+ **火男：** 避战拖延，开大时直接跑或上树，妖刀姬需等其大招结束再行动
+ **刘炼：** 躲球反制，开大后避免硬拼，队友配合时用大招顶球
+ **妖刀姬：** 大招博弈，右蓄可穿回阳柱子，大招快结束时按V多砍一刀，对红叶/紫萍不使用F2抓闪

---

### 4. 武器与魂玉细节

#### 不可磐石的招式

+ 绕背蓄力攻击
+ 匕首右蓄（豫让三伏）
+ 扇子蓄力接惊雷
+ 拳刃左右蓄力2.0

#### 魂玉技巧

+ **地堂霸脚：** 滑铲进蓝霸体可直接左键
+ **霸主+过关斩将：** W+转视角可拉开身位
+ **炽焰斩：** 难目押，建议配合弓箭三钉头练习

---

### 5. 应对敌方"捏蓝"策略

当预判敌方被打出僵直后会"捏蓝"（蓄力蓝色霸体）时，可以使用以下招式进行反制：

+ ✅ **奔跑A1 + 下劈：** 必须在奔跑状态下打出A1，否则会被蓝顶
+ ✅ **A1B2 + 下劈：** 连招后可接下劈抓蓝
+ ✅ **原地B1 + 下劈：** 原地B1后接下劈可以抓蓝
+ ❌ **奔跑B1 + 下劈：** 不能接，会被蓝顶

---

## 五、每日自省口诀

**战前五问 (Mental Checklist)**

1. **看人：** 是什么英雄？有什么技能？
2. **看位：** 队友在哪里？地形能否连招？
3. **看招：** 对手爱振刀吗？爱短闪吗？有没有交过F？
4. **操作：** 捏蓝了吗？控距了吗？有没有预输入？
5. **原则：** 紧张就拉扯，不要硬打；残血用远程，满血用远程压制

# 斩马刀进阶补遗：微操与针对性对策

> 以下内容补全了原笔记中关于特定判定、微操节奏、以及特定英雄的实战细节
>

---

## 一、容易被忽略的操作细节

### 1. 攻击与连招的细微节奏

+ **A人前的"防振"习惯：** `A人之前先捏一下蓝再A`
    - 目的：防对面预判振刀，增加判定吸附感
+ **连招的绝对禁忌：** 如果是**刀尖**（极限距离）左A打到了人，无论如何**不能接AB连招**（极易被振或打空），此时应寻求变招
+ **处决后的压制：** 打完处决后，推荐操作是 `前长闪 + 捏右键`，保持压制力
+ **蓝蓄拼刀后的连招：** 蓝蓄拼刀成功后，推荐连招为 `直接闪A → 抓A闪`，这比单纯的平A收益更高
+ **倒地起身：** 倒地翻滚起身可以**无缝直接进磐石**，这是反打的重要手段

---

### 2. 磐石与身法的补充

#### 对付"敲一下磐石就停手"的人

+ **解法：** `提前松开鼠标（活磐一下）` 或者 `战步观察`
+ 不要傻站着等死磐

#### 反勾技巧

+ 这是逃跑和反打非常实用的身法
+ **记得反勾，不要懒得用**

#### 下劈钩锁

+ 下劈完接钩锁压起身时，如果地形不好，操作要**稍微慢一点点**，防止失误

#### 活磐给压力

进入磐石状态后，敌方有三种主要应对方式：

**情况一：敌方预判死磐而振刀**

+ **应对：** 我们是"活磐"，可以等其振刀后，延迟出磐反击
+ 或用CA做假动作骗振

**情况二：敌方直接蓄力拼刀**

+ **应对：** 直接振刀
+ 对于能被"闪一振二"的蓄力，尽量使用该技巧，容错率更高

**情况三：敌方直接闪避拉开**

+ **应对：** 这是最难处理的情况，快放、慢放、抓闪都可能被反制
+ 此时直接使用远程武器是最有效的应对
+ 对手慢闪，可以长闪抓

---

## 二、武器针对性对策

### 1. 对战横刀

+ **左蓄应对：** 看到横刀左蓄，**用短闪躲，不要振刀**（横刀左蓄变招多，风险大）
+ **蓄力被扎：** 如果被横刀蓄力扎中了，第一时间按**短闪**

---

### 2. 对战双戟/双刀

+ **磐石应对石蓄：** 如果你用磐石架住了双戟的石蓄（石头），不要急着反击
+ 要 `后战步观察`，因为双戟后续变招极快

---

### 3. 对战匕首/扇子/飞索

+ **远程压制：** 斩马刀打这些高机动性或手短的武器，要多用 **壁击** 和 **远程武器** 消耗
+ 不要盲目拼近战

---

### 4. 针对特定武器的闪振技巧

针对不同武器的特定招式，可采用"闪一振二"或"碰瓷振"反制，但需警惕对手用钩锁打断或反向攻击。具体如下：

● 双截棍（B3）、双戟（右蓄后平击）、扇子（蓄力后平击）：使用"闪一振二"，对手可能用钩锁打断。
● 棍子（1.5s后续）：使用"碰瓷振"，对手可能用钩锁打断。
● 飞刀（B3）：使用"闪一振二"，对手可能在第二段反向放。
● 双刀（右蓄）：使用"短闪接长闪蓄力振"，对手可能在后半段反向攻击。

---

## 三、英雄特定交互

### 1. 魏青与"榴莲"/球（哈迪/岳山/虎对应）

+ **榴莲打魏青：** 要等被魏青锁住的瞬间再扔球/开大，否则容易空
+ **内战细节：** 球/榴莲内战，要**后手开大**，用自己的大招顶掉对面的球/状态
+ **掉刀机制：** 榴莲被振刀后，`F技能要早交`，不然刀会真的掉下来（防止被处决或丢刀）
+ **大招结束机制：** 榴莲大招结束后，球会自动结束，不能这时候才想起来扔

---

### 2. 崔三娘（水娘）与火男

+ **水泡泡交互：** 如果火男中了水泡泡（有受击状态），斩马刀 **右蓄1.0不要接惊雷**
    - 原因：会被火男的F顶掉并反抓
    - 斩马刀此时打右蓄即可，阔刀打左蓄
+ **玩水娘的禁忌：** 自己玩水娘时，尽量别出蓄力（容易被针对）

---

### 3. 宁红夜高阶博弈

+ **有F时的磐石：** 如果红夜手里有F，你磐石挡了她一下，此时最优解是：
    - **预输入柄击 + 捏住左键**
    - 这能防止她直接F破防或反打
+ **躲大招：** 红夜开大，先跑蓄力，快爆炸时再**大跳**

---

### 4. 妖刀姬补充

+ **穿墙：** 妖刀姬大招的右蓄可以穿透"回阳境"的柱子

---

## 四、补充的战术意识

### 血量博弈策略

+ **对面满血：** 用远程消耗
+ **对面残血：** 依然用远程收割（求稳）
+ **血量优势时：** 多骗振，或者慢放柄击，不要急着把优势送回去
