# 武器基础实用连招应对策略总结

> 作者/参考来源: 卡密、鼓手不洗头、付肖等

---

## 一、核心机制说明

### 1.1 蓄点阶段

+ **蓄力后进入蓄点阶段**，率先进入 1.0 的一方具有优势。此时，进入 1.0 的玩家在对局中占有先手优势。
+ **对手选择**: 对手的选择相对单一，通常为闪避、对刀或振刀，这些都是对蓄点的常见应对方式。

### 1.2 控距与目押

通过灵活的闪避与距离控制，玩家能够掌握对手的攻击范围，进而在面对多段蓄力攻击时进行有效的**控距目押**（即控制距离并通过准确的操作击破对方攻击，推荐采用蓄转振）。

## 二、各武器攻略大全 (连招 + 应对策略)

### 2.1 长剑

#### 基础连招

+ 长剑钩锁剑气: `bsb 升龙 → 钩锁 → 右蓄 1.0`
+ **长剑双钩锁**: `bsb 升龙 → 钩锁 → 撞人瞬间升龙 → 双跳 a` (有刻铭时最后跳 a 变成下劈)
+ `bsb 升龙 → 钩锁 → 升龙 → 985b + 跳a`

#### 处决连招

+ 第一段攻击命中 → 后长闪 b → 升龙/钩锁蓄力 (也可接双升龙双跳 a)

#### 蓄力应对策略

+ **左蓄**: 可通过下蹲躲避攻击
+ **右蓄**: 可进行长闪反抓后摇
+ **左右蓄**: 都可以进行控距目押, 贴脸可以抓蓄力后摇

赶路：跑 a 滑铲小跳（a可小捏控精力）

---

### 2.2 链剑

#### 基础连招

+ 钩锁剑气: `bsb 升龙 → 钩锁 → 右蓄 1.0`

#### 处决连招

+ 第一段攻击命中 → 后长闪 b → 升龙/钩锁蓄力 (也可接双升龙双跳 a)

#### 蓄力应对策略

+ **链剑应对**：左蓄绕开后可碰瓷震刀，右蓄需震剑轮或回收动作；右蓄后摇长，绕开可反抓；左蓄接金霸体后摇短难抓；短闪处理蓄力推荐双剑侧闪。
+ **左蓄**: wd长闪躲避并观察振刀 (碰瓷)
+ **右蓄**: 左右侧闪躲, 振剑轮或振收刀; 远端需要控距蓄转振; 贴脸右蓄是包可以碰瓷振的
+ **对手压起身**: 切拳起身规避

---

### 2.3 太刀

#### 基础连招

+ **钩锁百裂**: `asa 升龙 → 钩锁 → 右蓄 1.0` (刹那斩时为左蓄 1.0)
+ 太刀双升龙: `asa 升龙 → 钩锁 → 撞人瞬间升龙 w → 跳 a`

#### 处决连招

+ 处决第二刀命中瞬间 → 按住 w 轻拍空格 → 双跳 a

#### 蓄力应对策略

+ **左右蓄**: 无吸附判定, 攻击范围较近 (短闪可进入安全距离), 可通过**控距**进行振刀 (适合长剑、双截棍等)
+ **惊雷**: 看目押蓄转振, 长闪躲避抓僵直

#### 进阶技巧

+ **ACCA**: 太刀 a 到人一瞬间 → 长按 c → 点按 c → a

---

### 2.4 横刀

#### 基础连招

+ **钩锁百裂**: `asa 升龙 → 钩锁 → 右蓄 1.0`

#### 处决连招

+ 第一段攻击命中 → 后长闪 a → 升龙/钩锁蓄力 (也可接双升龙三跳 a)

#### 蓄力应对策略

+ **横刀应对**：横刀左蓄点刺突进动作慢，玩家可目压该动作释放蓄力或短闪；释放蓄力时，对手点刺会拼刀，转平 A 会被蓄力击中；短闪可躲点刺或平 A，但易被进攻技能抓僵直；点刺命中后左 A 压预输入，玩家僵直结束及时进蓝反顶，高延迟玩家选闪避更保险
+ **左蓄点刺**: 冲刺动作可通过**短闪**规避 (最优解为中闪, 后摇较小)
    - 观察对手选择: 若对手点刺并接 a, 可以选择直接出刀砍断
    - 也可以直接出蓄力, 点刺无法转振刀, 打法简单直接
+ **右蓄**: 侧闪一振二 (侧闪更优)

#### 进阶技巧

+ **ACCA**: 横刀 a 到人一瞬间 → 长按 c → 点按 c → a

赶路：跑 b；左蓄转曲步

---

### 2.5 阔刀

#### 基础连招

+ `升龙 → s闪 → a → a (狂潮) → 钩锁 → b`（棍阔，剑阔）

#### 蓄力应对策略

+ **打出死磐石**: 捏蓝目押
+ **打出活磐石**: 短闪后根据对方动作进行调整
+ **左蓄**: 不能被拼刀3.0
+ **右蓄**: 短闪一振二

#### 处决连招

+ 处决结束瞬间 → 轻拍空格 → 下劈

赶路：跑左蓄 接滑铲 跳a

---

### 2.6 斩马刀

#### 基础连招

+ `升龙 → s闪 → a → a (狂潮) → 钩锁 → b`（棍斩，剑斩）

#### 处决连招

+ 处决结束瞬间 → 小跳 → 下劈

#### 核心策略

少振多闪, 目押右蓄

#### 蓄力应对策略

+ **斩马刀应对**：玩家需主动出一刀打磐石，避免斩马刀转换为无敌磐石；死盘状态下，对手未战步可转正刀应对磐石反击；对手战步后，可在 1.0 节点续博弈，用长闪闪柄击仅能反抓对手捏左键情况；用右续 2.0 第二段破无敌磐石；对控活盘对手，可长闪绕背出刀或切弓箭钉头破盘，短兵器用 B 机破盘后接生龙式真连
+ **左蓄**: 无法直接目押时可闪一振二
+ **右蓄**: 多为贴脸捏蓝目押或长闪
+ **磐石**: 触发磐石只打一刀, 多段难目押
    - **活磐石**: 长闪绕背抓僵直
    - **无敌磐石**: 巴掌蓄力
+ **战步**:
    - 战步右蓄时捏蓝应对
    - 战步柄击可捏蓝目押振刀, 慢放柄击可找机会反抓
    - 磐石后战步 + 右蓄压力巨大, 可以转换思路: 使用长闪抓战步的后摇; 若有血量优势, 可以振战步后接柄击

---

### 2.7 长枪

#### 基础连招

+ `a → 升龙 → 钩锁 → 左蓄 1.0` (稳定版: `a → a → 跳a`)
+ `哪吒闹海 2 圈 → 升龙 → 钩锁 → b + a + ca`

#### 处决连招

+ 哪吒闹海第二段攻击结束瞬间 → 升龙 → 钩锁蓄力 (或接双升龙钩锁 a1 b2, 然后 ca 抓闪)

#### 蓄力应对策略

+ **左蓄**: 闪一振二
+ **右蓄**: 目押短闪规避
+ **1.5 控距目押**: 控制距离试探进行目押

---

### 2.8 长棍

#### 基础连招

+ `a → 升龙 → 钩锁 (人物白圈一点点) → 右蓄 1.0 → 跳 a`

#### 处决连招

+ 处决攻击结束后 → 轻拍空格小跳 a (非长剑对手时, 可第一段结束升龙 → 钩锁蓄力小跳 a)

#### 蓄力应对策略

+ **长兵器应对**：长枪左键可蹲伏规避，需等第二段伤害打完再出刀；长枪右续可绕后捏续博弈，长棍右续需走白步后长闪或碰瓷震刀；追击长棍 1.5 跑续时，勾索要抓立棍突进后摇。
+ **左蓄**: 大跳规避 (地面短闪); 观察对手动作, 若对手仍选择出招, 可以进行振刀
+ **右蓄**: 长闪一振二, 长闪尝试反抓
+ **1.5 控距目押**: 控制距离试探进行目押

赶路：滑铲升龙 与 跑 右蓄循环

---

### 2.9 双刀

#### 基础连招

+ `a闪a → 升龙 → 钩锁 → 右蓄 1.0` → 前长闪 b1 b2
+ `a → 升龙 → 钩锁 → 左蓄 1.0 → 惊雷` (铁马残红版)

#### 处决连招

+ 处决攻击结束后 → 立马跳 a → 下劈

#### 蓄力应对策略

+ **双刀右蓄应对**：双刀右键蓄力为多段连续伤害，玩家可通过转视角跳振碰瓷振刀；长闪绕右蓄会被吸闪，短闪时不能预输入动作，否则会打断无敌帧被尾气击中。
+ **双刀其他机制**：双刀左蓄可碰瓷但不推荐，对手能打断蓄力抓振刀后摇；右蓄后的惊雷可反放，但反放也会被跳振碰瓷，目压振惊雷若遇对手反放会被抓捏蓝，此类情况可用长闪应对。
+ **左蓄**: 目押或碰瓷振刀 (w + 跳 + 振刀)
+ **右蓄**: 压力较大, 拉开距离双闪 (修刀闪)
+ **太双**: 关键点进行闪避 (防止吸闪), 第四段强伪连, 第五段伪连

赶路：跑 b 接闪

---

### 2.10 双戟

#### 基础连招

+ `a → 升龙 → 钩锁 → 右蓄 1.0`
+ `左蓄挑中人 → 按住 s 调整视角 → a → 钩锁 → b → 升龙 → 下劈`

#### 处决连招

+ 处决攻击结束后 → 立马跳 a → 下劈

#### 蓄力应对策略

+ **双戟蓄力应对**：双戟右键蓄力，玩家推荐用双剑侧短闪（WA 或 WD 短闪）或 R 闪应对，短闪成功后可碰瓷振刀；双戟左蓄仅命中第一段尾段时，对手长闪出刀可抓捏蓝。
+ **左蓄 (冲挑劈)**: 躲避冲刺, 观察对手动作
+ **右蓄**: 压力较大, 拉开距离双闪 (修刀闪); 贴脸 wa 左前短闪, sd 右后短闪碰瓷振刀

赶路：左蓄闪打断挑

---

### 2.11 匕首

#### 基础连招

+ `左蓄亢龙卷破 → 侧闪鬼反 → a → ca → b`
+ `豫让三伏扎两下 → 后长闪 → 升龙 → 空 a 两下 → 下劈`

#### 处决连招

+ 处决攻击结束后 → 立马跳 a → 下劈

#### 蓄力应对策略

+ **匕首应对**：白刀接 A2B2 可在延迟理想时开技能反顶；白刀 A2 抓捏篮招式低延迟易闪，高延迟会被吸闪；捏跑防抓闪可被飞刀弹刀克制；飞刀能抓匕首放空的左蓄；鬼反可用跳震吸附碰瓷震刀
+ **左蓄**: 控距长闪目押, 飞刀、双持可尝试抓飞天后摇
+ **右蓄**: 短闪 (大跳 a), 防止连击 (ca)
+ **鬼反**: 跳振碰瓷

赶路：跑 b 接闪循环

---

### 2.12 扇子

#### 基础连招

+ `双吹风 → 闪 → ca → b → ca → b`
+ 壁击接升龙 + 985右蓄

#### 处决连招

+ 第一段攻击命中后 → 立马升龙 → 钩锁蓄力下劈

#### 蓄力应对策略

+ **扇子应对**：玩家可蹲伏躲避扇子左蓄（需对手进入蓄点后操作，仅战斗状态可用，不能用双持和飞刀）；低延迟玩家蹲振二时尽量用双剑震刀；也可用带低头动作的蓄力（如太刀左蓄、长剑右蓄）规避左蓄；应对贴脸吹风，可跟闪抓第二次吹风前摇，或用飞刀弹刀
+ **左蓄**: 下蹲并振二段
+ **右蓄**: **贴脸**长闪一振二, 侧短闪抓后摇
+ **惊雷**: 难目押, 蹲一振二, 闪一振二
+ **节奏二次进蓄快**: 最好保持距离，打乱对手节奏

---

### 2.13 双截棍

#### 基础连招

+ 拳切985

#### 处决连招

+ 攻击结束后 → 轻拍空格小跳 a → 下劈

#### 蓄力应对策略

+ **双截棍应对**：横栏反击推荐用保留无敌帧的修刀闪拉开；左续可通过短接修刀长闪抓后摇，或用跳震勾应对不同取消方式；非习攻击需慢起身后接慢短闪，或切短兵器捏防抓闪起身
+ **左蓄**: 闪一振二; 进阶: 短闪一段后跳振勾
+ **右蓄**: 长闪躲避, 白刀抓 (双截棍、飞刀、拳刃、双持)
+ **横栏**: 修刀闪 (干净闪), 观察对手动作
+ **飞袭**: 不起身, 切刀起身

赶路：跑 b 可小捏精力也可 2b

---

### 2.14 拳刃

#### 基础连招

+ `asa 升龙 → 3 个 b → ca`

#### 处决连招

+ 处决攻击结束后 → 按住 w → 双跳 a

#### 蓄力应对策略

+ **拳刃应对**：左蓄多段伤害可用转视角跳震碰瓷；左蓄 1.0 命中后接跳 A，可前短闪规避后反抓；二点零命中后对手转龙白可捏篮反顶；右蓄二点零可闪一震二
+ **左右蓄**: 可通过大跳应对
+ **左蓄**: 长闪振刀 (修刀闪)
+ **右蓄**: 短闪振二
+ **闯步**: 蓄力目押闯步放蓝; 长闪抓闯步, 若抓不到可再次闪避躲避

赶路：跑 b 接闪（可适当加 b）

---

### 2.15 飞刀

弹刀：**敌人先出攻击（平 A / 蓄力），你后用右键（B 键）精准命中其攻击瞬间**（非同时，否则拼刀）

跑路技巧：a + 2b + 长闪

#### 基础连招

+ `asa → 升龙 + 钩锁 → b a a`

#### 处决连招

+ 处决攻击结束后 → 立马跳 a → 下劈

#### 蓄力应对策略

+ **飞刀机制应对**：飞刀左蓄持续时间长，玩家在距离合适时可碰瓷振；非完美绕开蓄力不建议抓后摇，蓄力接惊雷后摇极短，出刀会被惊雷击中；飞刀惊雷有霸体残流，出刀抓后摇会被反顶，推荐抢先蓄博弈；飞刀二 A 接升龙可抓捏蓝，抓闪钩可通过捏蓝反抓对手
+ **贴脸飞刀**: 贴脸给压力, 长闪绕背是一个不错的选择
+ **左蓄**: 短闪 (干净闪) 躲避尾气
+ **右蓄**: 振第三段攻击
+ **惊雷**: 闪避, 控距目押

---

### 2.16 千机伞

伞：

+ `a 闪 a + 升龙 钩锁 + 左蓄 1.0 + b`（强伪）
+ 双压连招：`左蓄1.0 + b + b + 升龙满钩锁 + b + a`

盾：

+ `右蓄1段 钩锁打断 b + a`

## 三、高级技巧

### 3.1 通用技巧

**拳切985 连招** (长棍、长剑、太刀、横刀、双截棍适用, 稳定性不够, 需勤练习):

+ `a → 升龙 (右键不松) → 最高点切拳 → 切出来点s闪 → 滚轮切 → 右键 1.0`

### 3.2 蓄力博弈策略补遗

+ **抓闪失误补救**：该口诀是玩家抓闪出刀失误后的补救措施。抓闪出刀过早砍中对手无敌帧时，玩家需直接捏蓄应对；出刀过晚让对手进蓝时，玩家要出短闪或短接修刀闪，降低对手蓝顶成功率，短闪被抓更依赖对手预判，玩家还能补修刀闪防抓。
+ **先蓄方博弈策略**：先蓄方有先进 1.0 的霸体优势，后蓄方在自身进入 1.0 时直出蓄力的概率极高，先蓄方此时振刀是最优振点；若观察到对手提前转振刀，先蓄方有时间反应释放压振蓄力。
+ **后蓄方博弈策略**：后蓄方任何博弈选择的风险均大于收益，最优选择是用手段拉开距离，寻找同蓄或先蓄的机会重新开启博弈。

---

## 总结

本攻略覆盖了游戏中所有武器的核心连招、处决技巧以及蓄力阶段的应对策略。熟练掌握这些技巧需要大量练习, 建议根据自己使用的武器重点练习相关连招, 同时了解其他武器的特性以便更好地应对不同对手。
